# 交易規劃助手 TradePlan（TradingView 指標）

在 TradingView 圖上點三下（進場、止損、止盈），自動算出**該下幾手**、**R:R**、**風險與預估獲利**，並模擬保本、部分止盈與移動止損，到點時發出警報。

> ⚠️ 本工具**不會幫你下單**。它是計算、視覺化與警報工具，實際下單仍需你在券商平台操作（或自行串接 webhook）。

---

## 功能一覽

| 功能 | 說明 |
|---|---|
| 圖上點選點位 | 加到圖上時依序點選進場、SL、TP，之後可直接拖動 |
| 自動判斷方向 | 進場價高於 SL 為做多，低於 SL 為做空 |
| 手數計算 | 依「% 餘額」或「固定金額」風險計算，依最小手數單位無條件捨去 |
| 自動換匯 | 報價幣別與帳戶幣別不同時自動換算（例如 USDJPY → USD 帳戶） |
| R:R 止盈 | TP 可手動點選，或依 R:R 倍數自動計算 |
| 保本 | 獲利達 N 倍 R 時，止損移到成本（可加點） |
| TP1 部分止盈 | 設定 R 倍數與平倉百分比，到點時提醒 |
| 移動止損 | ATR／擺動高低點／均線／拋物線 SAR 四選一，可設定獲利幾 R 才啟動 |
| 資訊面板 | 方向、進場、SL/TP pips、R:R、風險金額、手數、預估獲利、目前止損、狀態 |
| 警報 | 進場、TP1、移保本、移動止損、止盈、止損，訊息為 JSON 格式，可直接接 webhook |

## 安裝

1. 開啟 TradingView 圖表，點下方 **Pine 編輯器**。
2. 貼上 `TradePlan_v1.pine` 全部內容，按 **加到圖表**。
3. 依提示在圖上點三下：**進場點 → 止損 SL → 止盈 TP**。

## 設定說明

### ① 交易點位
- **止盈方式**：「依 R:R」會忽略你點的 TP，改用 R:R 目標自動計算；「手動價格」則使用你點的 TP。

### ② 風險與手數
- **帳戶幣別／帳戶餘額**：TradingView 讀不到你的券商帳戶，請手動填寫。
- **風險方式**：`% 餘額` 或 `固定金額`。
- **每手合約數量**：填 0 時自動判斷；填了數字會直接取代自動值。

  | 商品 | 填 0 時 | 建議 |
  |---|---|---|
  | 外匯 | 100,000 | 維持 0 |
  | 期貨 | 交易所的每點價值（例如 GC 為 100） | 維持 0，手數即口數 |
  | 股票、加密貨幣 | 1（以股／顆計） | 通常維持 0 |
  | 黃金、指數等差價合約 | **不計算手數，面板會提醒** | **依券商規格填寫**（例如 XAUUSD 常見為 100） |

- 匯率換算失敗、或風險金額不足一個最小手數時，面板會顯示原因，不會給出可能錯誤的手數。
- 進場後手數會鎖定，不會因匯率變動而改變。
- **手數最小單位**：一般為 0.01。

### ③ 保本
- **觸發（R 倍數）**：獲利達幾倍風險時移保本。
- **保本加點**：移到成本後再多鎖幾 pips。

### ④ 部分止盈
- 設定 TP1 的 R 倍數與平倉 %，到點時面板打勾並發出警報（指標不會真的平倉）。

### ⑤ 移動止損
- **方式**：ATR、擺動高低點、均線、拋物線 SAR。
- **啟動（R 倍數）**：獲利達幾 R 後才開始移動。
- 止損只會往有利方向移動，不會倒退。

## 設定警報

1. 圖表上按 **警報（鬧鐘圖示）**。
2. 條件選 **TradePlan** → **任何 alert() 函式呼叫**。
3. 需要串接自動下單時，勾選 Webhook URL 並填入你的接收端網址。

警報訊息範例：

```json
{"event":"move_sl_breakeven","symbol":"EURUSD","side":"sell","price":1.10100,"lots":0.25,"remaining_lots":0.25,"size_ok":true,"sl":1.10100,"tp":1.09700}
```

| 欄位 | 意義 |
|---|---|
| `lots` | 這個事件要處理的手數：進場＝全部；部分止盈＝這次平掉的；移動止損、止盈、止損＝目前剩餘的 |
| `remaining_lots` | 事件之後剩下的手數 |
| `size_ok` | `false` 表示算不出有效手數，此時 `lots` 與 `remaining_lots` 為 `null`，**接收端不應下單** |

> **從 v1 升級：** v1 的 `lots` 永遠是全部手數。如果你已經串接 webhook，請改用上表的意義。更新腳本後也要刪掉舊警報重新建立，新版才會生效。

`event` 可能的值：`entry`、`partial_close_50pct`、`move_sl_breakeven`、`move_sl_trailing`、`take_profit`、`stop_out`

## 已知限制

- 警報在 **K 線收盤** 才送出，盤中觸價會稍有延遲。
- 同一根 K 線同時碰到 SL 和 TP 時，保守視為先碰 SL。
- 進場那根 K 線也會檢查 SL：之後才觸價進場的 K 線碰到 SL 就算止損；你點選的那根 K 線分不出先後，收盤超過 SL 才算。
- 價格跳空越過進場價時，不會判定為進場。
- 「預估獲利」是全部手數都到 TP 的金額，沒有扣除 TP1 提早平倉的部分。
- 不會下單、改單或平倉。
- 計算結果僅供參考，請以券商實際合約規格為準。

## 更新紀錄

### v1.1
- 修正黃金、指數差價合約沒填合約數量時，手數會放大的問題（XAUUSD 以每手 100 計為 100 倍）。
- 修正期貨填寫合約數量時重複乘上每點價值，導致手數過小的問題。
- 匯率換算失敗時不再以 1 計算。
- 警報的 `lots` 會扣除 TP1 已平倉的部分，並新增 `remaining_lots`、`size_ok`。
- 手數在進場時鎖定。
- 進場的 K 線也會檢查止損。
- 手數太小無法分批時，不再發出 TP1 警報。
